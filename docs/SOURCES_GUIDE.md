## 🔧 Source Configuration

### Enabling/Disabling Sources

Edit `config/sources.json`:

```json
{
    "name": "Source Name",
    "enabled": true,  // ← Change to false to disable
    "priority": "high"
}
```

### Adding Custom Sources

Add to `config/sources.json`:

```json
{
    "name": "Custom Source",
    "url": "https://example.com/rss",
    "type": "rss",
    "language": "en",
    "category": "custom",
    "reliability": 7,
    "enabled": true
}
```
