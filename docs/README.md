# 🛡️ WATCHKEEPER

Autonomous Intelligence System for Missionary Protection

## Overview

WATCHKEEPER is an AI-powered intelligence platform designed specifically to protect and support missionary work through early threat detection, opportunity identification, and comprehensive situational awareness.

## Features

- 🤖 **Autonomous AI Agents**: Self-directed web investigation
- 🌍 **Global Intelligence**: Multi-source data collection
- ⚡ **Real-time Alerts**: Immediate threat notifications
- 🎯 **Missionary Focus**: Specialized for missionary contexts
- 🛡️ **Stealth Operation**: Undetectable web browsing
- 📊 **Intelligence Analysis**: AI-powered threat assessment

## Quick Start

1. **Setup**: Run `./setup.sh` or `python3 scripts/install_dependencies.py`
2. **Test**: Run `python3 scripts/test_system.py`
3. **Demo**: Run `python3 guardian.py --demo`
4. **Monitor**: Run `python3 guardian.py --monitor`

## System Requirements

- macOS 10.10+ (optimized for 2014 Mac Mini)
- Python 3.8+
- 4GB+ available RAM
- Stable internet connection (10+ Mbps)

## Configuration

Edit `config/settings.json` to customize:
- Threat assessment thresholds
- Intelligence sources
- Monitoring intervals
- Alert preferences

## Support

For issues or questions, check the logs in `data/logs/guardian.log`
